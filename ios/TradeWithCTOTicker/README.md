# TradeWithCTO iPhone ticker

Open `TradeWithCTOTicker.xcodeproj` in Xcode.

1. For the app and the TradeWithCTOTickerWidget target, set Signing & Capabilities → Team to your Personal Team.
2. Connect your iPhone, select it as the run destination, and press Run.
3. A free Personal Team profile expires about every 7 days. Open the project and Run again when the phone will not launch the app.
4. In the app, keep the server URL and paste the app token from settings.html → Live ticker.

The Live Activity stays on this iPhone. Push is not used.
